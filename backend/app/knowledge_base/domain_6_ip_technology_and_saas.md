# Domain 6: Intellectual Property & Technology Law Knowledge Standard

---

## Governing Statutory Framework
* **Digital Personal Data Protection (DPDP) Act, 2023 & GDPR**: Mandates explicit consent, data minimization, user rights, data principal access, and heavy penalties for breaches.
* **Copyright Act, 1957 & Patents Act, 1970**: Governs software code ownership, work-for-hire provisions, patentability exclusions (Section 3k), and licensing rights.
* **Information Technology Act, 2000 (Section 43A & 79)**: Intermediary liability, reasonable security practices, and cybersecurity incident reporting (CERT-In 6-hour mandate).
* **Trade Marks Act, 1999**: Protection of brand names, domain names, and trademarks against infringement and passing off.

---

## RED FLAGS (Critical / Fatal Tech Exposure)
1. **Open Source Software (OSS) Copyleft Infection**: SaaS or software license permitting GPL/AGPL code integration that forces commercial source code disclosure.
2. **Uncapped Third-Party IP Infringement Liability**: Vendor or client forced to provide uncapped financial indemnification against patent/copyright claims.
3. **Data Ownership Surrender**: SaaS terms granting the service provider broad commercial ownership or model-training rights over user's proprietary data.
4. **Source Code Ownership Shift Under Work-For-Hire**: Broad provisions assigning developer's underlying frameworks, utility libraries, and pre-existing core tools to the client.
5. **No Data Breach Notification & Liability Shift**: Vendor disclaiming all responsibility for security breaches or data loss while processing personal data.

---

## YELLOW FLAGS (Small Concerns to Verify with Lawyer)
1. **Low SLA Availability Commitments (<99.0%)**: Service level agreements lacking service credit payouts for downtime.
2. **Broad License Scope (Irrevocable, Perpetual for Temporary Services)**: Customer granting vendor broad perpetual license to use customer branding.
3. **Short Data Retention Post-Termination (<30 Days)**: Automatic deletion of customer database backups immediately upon contract expiration.

---

## GREEN FLAGS (Protective & Standard Market Terms)
1. **Super-Cap on Infringement Indemnity (2x-5x Annual Fees)**: Predictable liability caps for IP disputes.
2. **Explicit Customer Data Ownership & Zero Model Training**: Data processor acts strictly on instructions without retaining user data.
3. **Carve-Out for Pre-Existing Developer IP**: Developer retains ownership of core background technology and reusable modules.
4. **Comprehensive Data Processing Agreement (DPA)**: Full DPDP/GDPR compliance with 72-hour breach reporting and audit rights.
